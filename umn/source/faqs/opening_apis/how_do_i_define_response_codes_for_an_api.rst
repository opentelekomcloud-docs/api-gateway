How Do I Define Response Codes for an API?
==========================================

There are two types of responses:

-  Gateway response codes: returned by the gateway for API requests that are throttled, denied, or failed in authentication. For details, see :ref:`Customizing Error Response for APIs <apig_03_0008>`.
-  Backend service responses: defined by backend API services (API providers) and transparently transmitted by APIG.
