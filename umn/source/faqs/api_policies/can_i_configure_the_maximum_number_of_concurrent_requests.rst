Can I Configure the Maximum Number of Concurrent Requests?
==========================================================

No.

-  However, you can define the maximum number of API calls within a specific time period.
-  A single API can be accessed for a maximum of 6,000 times per second. For details, see :ref:`Notes and Constraints <apig-pd-180307005>`.
-  The number of API calls can be controlled using a request throttling policy. For details, see :ref:`Configuring API Request Throttling <apig_03_0025>`.
