How Do I Call an API Using App Authentication in iOS System?
============================================================

APIG provides SDKs and demos in multiple languages, such as Java, Python, C, PHP, and Go, for app authentication.

To use Objective-C (for iOS) or other languages, see "App Authentication" in the *API Gateway Developer Guide*.
