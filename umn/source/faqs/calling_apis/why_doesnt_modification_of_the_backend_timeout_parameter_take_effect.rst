Why Doesn't Modification of the backend_timeout Parameter Take Effect?
======================================================================

Problem Description
-------------------

Modification of the **backend_timeout** parameter in gateways does not take effect.

Possible Causes
---------------

**Timeout (ms)** is not modified in the **Basic Information** area.

Solution
--------

On the APIG console, go to the API details page, click **Modify**, and modify the **Timeout (ms)** parameter on the **Basic Information** page.
