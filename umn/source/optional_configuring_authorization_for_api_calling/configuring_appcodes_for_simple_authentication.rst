Configuring AppCodes for Simple Authentication
==============================================

AppCodes are identity credentials of a credential used to call APIs in simple authentication mode. In this mode, the **X-Apig-AppCode** parameter (whose value is an AppCode on the credential details page) is added to the HTTP request header for quick response. APIG verifies only the AppCode and the request content does not need to be signed.

Precautions
-----------

Simple authentication does not require complex signature processes. However, the AppCode is transmitted in plaintext, which may bring security risks. Therefore, do not carry privacy information.

Prerequisites
-------------

-  You have created an API using app authentication and enabled simple authentication. If no, create one by referring to :ref:`Creating an API <apig_03_0128>`. After you enable simple authentication for an existing API, you need to publish the API again to make the configuration take effect.
-  You have created a credential and bind it to an API that uses app authentication. If no, create one by referring to :ref:`Configuring Authentication Credentials <apig_03_0056>`.

Constraints
-----------

-  For security purposes, simple authentication only supports API calls over HTTPS or gRPCS.
-  You can create a maximum of five AppCodes for each credential.

Generating an AppCode
---------------------

#. Go to the APIG console.
#. Select a dedicated gateway at the top of the navigation pane.

3. In the navigation pane, choose **API Management** > **Credentials**.

4. Click the name of the target credential.

5. Under **AppCodes**, click **Add AppCode**.

6. Configure the AppCode in the dialog box based on the following table.

   .. table:: **Table 1** AppCode configuration

      +-----------------------------------+--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
      | Parameter                         | Description                                                                                                                                                                                                                          |
      +===================================+======================================================================================================================================================================================================================================+
      | AppCode Type                      | Select the method for generating an AppCode.                                                                                                                                                                                         |
      |                                   |                                                                                                                                                                                                                                      |
      |                                   | -  **Automatically generated**: An AppCode is generated by the system.                                                                                                                                                               |
      |                                   | -  **Custom**: Specify an AppCode.                                                                                                                                                                                                   |
      +-----------------------------------+--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
      | AppCode                           | Enter an AppCode if you set AppCode Type to **Custom**.                                                                                                                                                                              |
      |                                   |                                                                                                                                                                                                                                      |
      |                                   | An AppCode is a unique identifier for calling an API. Enter 64 to 180 characters, starting with a letter, digit, plus sign (+), or slash (/). Only letters, digits, and the following special characters are allowed: ``+_!@#$%-/=`` |
      +-----------------------------------+--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+

7. Click **OK**.

8. After the AppCode is added, you can use it for simple authentication of API requests.

   When sending a request, add the **X-Apig-AppCode** parameter to the request header and omit the request signature.

   For example, when using curl, add the **X-Apig-AppCode** parameter to the request header and set the parameter value to the generated AppCode. For example, the AppCode is **xhrJVJKABSOxc7d***********FZL4gSHEXkCMQC**.

   .. code-block::

      curl -X GET "https://api.exampledemo.com/testapi" -H "content-type: application/json"  -H "host: api.exampledemo.com" -H "X-Apig-AppCode: xhrJVJKABSOxc7d***********FZL4gSHEXkCMQC"
