Viewing API Call Logs
=====================

APIG provides visualized analysis and statistics of APIs, allowing you to view API calling logs.

Prerequisites
-------------

-  APIs have been called.
-  A log group has been created. If no log group is available, `create one <https://docs.otc.t-systems.com/en-us/usermanual/lts/lts_04_0003.html>`__.
-  A log stream has been created. If no log stream is available, `create one <https://docs.otc.t-systems.com/log-tank-service/umn/log_management/managing_log_streams.html>`__.


Viewing API Call Logs
---------------------

#. Go to the APIG console.
#. Select a gateway at the top of the navigation pane.
#. In the navigation pane, choose **Monitoring & Analysis** > **Log Analysis**.
#. Enable log analysis.

   a. On the **Log Analysis** tab page, click **Configure Logs and Tracing**.
   b. In the displayed dialog box, configure log information and click **OK**.

   .. table:: **Table 1** Configuring log information

      +-----------------------------------+-----------------------------------------------------------------------------------------------------------------------------------------+
      | Parameter                         | Description                                                                                                                             |
      +===================================+=========================================================================================================================================+
      | Collect Logs                      | Indicates whether to enable log collection. By default, it is disabled. You can view API call logs only after the parameter is enabled. |
      +-----------------------------------+-----------------------------------------------------------------------------------------------------------------------------------------+
      | Log Group                         | Select the log group to which the log stream belongs.                                                                                   |
      |                                   |                                                                                                                                         |
      |                                   | If there is no log group you want to select, click **View Log Groups** to go to the LTS console and create one.                         |
      +-----------------------------------+-----------------------------------------------------------------------------------------------------------------------------------------+
      | Log Stream                        | Select the log stream for storing the API call logs.                                                                                    |
      |                                   |                                                                                                                                         |
      |                                   | If there is no log stream you want to select, click **View Log Streams** to go to the LTS console and create one.                       |
      +-----------------------------------+-----------------------------------------------------------------------------------------------------------------------------------------+

5. View the calling logs of all open APIs in real time on the console.

   -  Log search: You can search for and analyze the collected log data. For details, see "Log Search and Analysis" in the *Log Tank Service User Guide*.
   -  Statistical charts: Query results can be displayed in charts, helping you easily understand changes in log data. For details, see "Visualizing Logs in Statistical Charts" in the *Log Tank Service User Guide*.
   -  Real-time logs: You can view logs reported in real time to quickly search for and analyze log data. For details, see "Viewing Real-Time Logs" in the *Log Tank Service User Guide*.
   -  For details about API Gateway log fields, see :ref:`Table 2 <apig_03_0042__table179941643151711>`.
   -  To export logs, see section "Log Transfer" in the *Log Tank Service User Guide*.
