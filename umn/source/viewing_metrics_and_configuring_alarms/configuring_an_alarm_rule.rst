Configuring an Alarm Rule
=========================

By creating alarm rules, you can customize the monitored objects and notification policies to monitor the running status of API Gateway in real time and receive warnings.

Creating an Alarm Rule
----------------------

#. Go to the APIG console.
#. Select a gateway at the top of the navigation pane.

3. In the navigation pane, choose **API Management** > **API Groups**.

4. Click a group name to go to the **Group Information** page.
5. On the **Monitoring** area of the **APIs** tab, click **More** to access the Cloud Eye console. Then create an alarm rule. For details, see `Creating an Alarm Rule <https://docs.otc.t-systems.com/en-us/usermanual/ces/en-us_topic_0084572213.html>`__.
