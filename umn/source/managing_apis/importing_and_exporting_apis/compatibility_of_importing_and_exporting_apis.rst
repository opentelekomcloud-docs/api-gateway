Compatibility of Importing and Exporting APIs
=============================================

OpenAPI Specification (OAS) and APIG object definitions are different in terms of object mapping, parameter types, and path syntax. For details, see the following description:

-  APIG supports OAS.

   OAS defines a standard, language-agnostic interface to RESTful APIs. OAS is the successor of Swagger Specification. APIG supports two sets of OpenAPI specifications: Swagger 2.0 and OpenAPI 3.0. **In this document, Swagger refers to Swagger 2.0 and OpenAPI refers to OpenAPI 3.0.**

-  APIG allows you to import and export the APIs that comply with the OAS specifications, and add :ref:`extended fields <apig_03_0084>` to the imported APIs.

-  Data conversion and synchronization between OAS and APIG objects are implemented through mapping rules. For details about these rules, see :ref:`Table 1 <apig_03_0083__en-us_topic_0139502395_table158531553154813>`.

-  There are different specifications for OAS and APIG parameter types. For details, see :ref:`Table 2 <apig_03_0083__en-us_topic_0139502395_table7778357134316>`.

-  There are syntax differences between OAS and APIG API request paths. For details, see :ref:`Table 3 <apig_03_0083__en-us_topic_0139502395_table14961789020>`.
