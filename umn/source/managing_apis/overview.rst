Overview
========

After an API is created, you can perform the following operations to manage the API:

-  :ref:`Viewing or Modifying API Information <apig_03_0016>`: View the basic information about an API and edit them if needed.
-  :ref:`Configuring Custom API Authentication <apig_03_0029>`: Configure custom authentication.
-  :ref:`Configuring API Parameter Orchestration Rules <apig_03_0110>`: Configure different algorithm rules to map new request parameters.
-  :ref:`Customizing Error Response for APIs <apig_03_0008>`: Configure custom response status codes or gateway response content.
-  :ref:`Cloning an API <apig_03_0076>`: Clone an API to quickly create an API with the same basic information.
-  :ref:`Taking an API Offline <apig_03_0070>`: Take an API offline to stop providing services. **This operation will cause the APIs to be inaccessible in the environments. Ensure that you have notified users before this operation.**
-  :ref:`Importing and Exporting APIs <apig_03_0082>`: Import APIs to APIG using API design files and CCE workloads, or export APIs from APIG to your local PC.
-  :ref:`API Design File Extension Definitions <apig_03_0084>`: Configure the API design file by referring to the extended definitions supported by APIG.
